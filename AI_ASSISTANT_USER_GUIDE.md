## 🚀 How to Use

### 1. Starting a New Booking

**Option A - Click Quick Action Button:**
```
Click: [📅 New Booking] button
```

**Option B - Type in chat:**
```
Type: "new booking" or "book room"
```

---

### 2. Using the Calendar Picker

**When bot asks for date:**
```
✅ AUTOMATIC: Calendar picker appears
🎯 ACTION: Click on the calendar input
📅 SELECT: Choose your date
✔️ CONFIRM: Click "Confirm" button
```

**Benefits:**
- No typing required
- No date format errors
- Visual calendar interface
- Can't select past dates
- Mobile-friendly

---

### 3. Using the Room Dropdown

**When bot shows available rooms:**
```
✅ AUTOMATIC: Dropdown menu appears
🎯 ACTION: Click the dropdown
📋 VIEW: See all available rooms with prices
🛏️ SELECT: Choose your preferred room
✔️ CONFIRM: Click "Confirm" button
```

**What you see:**
```
Room 101 - Deluxe Room (₹2500/night)
Room 102 - Standard Room (₹1500/night)
Room 103 - Suite (₹3500/night)
```

**Benefits:**
- No typing room numbers
- See prices immediately
- Only available rooms shown
- No selection errors
- Easy comparison

## 🎯 Complete Booking Example

### Step-by-Step:

**1. Click [New Booking]**
```
Bot: 🏨 Great! Let's create a new booking.
     Please provide the guest's name:
```

**2. Type guest name**
```
You: John Doe
Bot: ✅ Guest Name: John Doe
     Please provide the check-in date:
```

**3. Use Calendar Picker**
```
[Calendar appears]
📅 Select: October 15, 2025
✔️ Click: Confirm

Bot: ✅ Check-in: 2025-10-15
     Please provide the check-out date:
```

**4. Use Calendar Picker Again**
```
[Calendar appears]
📅 Select: October 17, 2025
✔️ Click: Confirm

Bot: ✅ Check-out: 2025-10-17
     How many guests will be staying?
```

**5. Type number of guests**
```
You: 2
Bot: ✅ Number of guests: 2
     🛏️ Available rooms for your dates:
```

**6. Use Room Dropdown**
```
[Dropdown appears with room options]
🛏️ Select: 101 - Deluxe Room (₹2500/night)
✔️ Click: Confirm

Bot: ✅ Room Selected: 101 - Deluxe Room
     📋 Booking Summary:
     • Guest: John Doe
     • Check-in: 2025-10-15
     • Check-out: 2025-10-17
     • Guests: 2
     • Room: 101 - Deluxe Room
     • Nights: 2
     • Total: ₹5000
     
     💳 Has the payment been received?
     Type "paid" or "pending":
```

**7. Type payment status**
```
You: paid
Bot: 🎉 Booking Created Successfully!
     📋 Booking ID: #123
     [Full details shown]
```

## 💡 Pro Tips

### Tip 1: Cancel Input
```
If you accidentally trigger calendar or dropdown:
→ Click "Cancel" button
→ Returns to normal chat
```

### Tip 2: Manual Entry
```
You can still type dates manually:
Format: YYYY-MM-DD (e.g., 2025-10-15)
```

### Tip 3: Mobile Usage
```
On mobile:
→ Tap date input for calendar
→ Tap dropdown for room selection
→ Large touch targets
→ Swipe to scroll chat
```

### Tip 4: Quick Navigation
```
Click links in bot messages:
→ "View your booking list" → Goes to bookings page
```

### Tip 5: Error Recovery
```
If something goes wrong:
→ Bot shows clear error message
→ You can retry immediately
→ No data lost from previous steps
```

## ❓ Troubleshooting

### Calendar not showing?
```
✓ Refresh the page
✓ Check browser compatibility
✓ Try typing date manually: YYYY-MM-DD
```

### Dropdown not showing?
```
✓ Wait for bot to show available rooms
✓ Refresh if needed
✓ Type room number manually if preferred
```

### Can't click buttons?
```
✓ Scroll down to see buttons
✓ Check screen size (zoom level)
✓ Refresh browser
```

### Messages not appearing?
```
✓ Check internet connection
✓ Refresh the page
✓ Check console for errors (F12)
```
