# Quick Start Guide - New UI

## 🎯 How to Use the Enhanced Interface

### First Time Setup
1. **Clear Browser Cache**
   - Chrome/Edge: `Ctrl + Shift + Delete` (or `Cmd + Shift + Delete` on Mac)
   - Select "Cached images and files"
   - Click "Clear data"

2. **Hard Refresh**
   - Windows/Linux: `Ctrl + F5`
   - Mac: `Cmd + Shift + R`

3. **Open Application**
   - Visit: http://127.0.0.1:5000
   - Login with your credentials

---

## 📱 Mobile Usage Tips

### Navigation
- **Tap the menu icon** (☰) in the top-right to open the navigation menu
- Menu items will show with a smooth slide-in animation
- Tap anywhere outside the menu to close it

### Dashboard Cards
- **Stats cards** will stack vertically on mobile
- Each card shows large numbers for easy reading
- Tap cards to see more details (if enabled)

### Tables
- **Swipe left/right** to see all columns in tables
- Tap row to select/view details
- Use the search function to filter results

## 🎯 Common Tasks

### Adding a New Hotel
1. Click **"Add New Hotel"** in Quick Actions (right sidebar)
2. Fill in the form with hotel details
3. Click **"Submit"** - button shows loading spinner
4. Success alert appears at the top
5. Redirected to hotel list

### Viewing Hotel Details
1. Find hotel in the **Recent Hotels** table
2. Click **"View"** button
3. Hotel details page opens
4. All information displayed in organized cards

### Managing Bookings
1. Click **"Bookings"** in navigation
2. Use search to find specific booking
3. Click row to view details
4. Use action buttons to check-in/out

### Checking Stats
1. View dashboard for at-a-glance metrics
2. **Blue card** = Total Hotels
3. **Green card** = Total Rooms
4. **Cyan card** = Monthly Bookings
5. **Amber card** = Monthly Revenue

## 🛠️ Troubleshooting

### Issue: Animations Not Working
**Solution**: 
- Enable JavaScript in browser
- Update to latest browser version
- Clear cache and hard refresh

### Issue: Layout Looks Broken
**Solution**:
- Clear browser cache
- Hard refresh (Ctrl+F5)
- Check browser compatibility

### Issue: Mobile Menu Won't Close
**Solution**:
- Tap outside the menu
- Tap a menu item
- Refresh the page

### Issue: Colors Look Different
**Solution**:
- Disable browser dark mode extensions
- Check display color settings
- Ensure CSS file loaded correctly

### Issue: Buttons Not Responding
**Solution**:
- Check if JavaScript is enabled
- Look for errors in browser console (F12)
- Refresh the page
